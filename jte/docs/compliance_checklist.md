## 1. JT/T 808-2019 终端通信协议

### 1.1 消息头与帧格式
- [x] 消息标识符 0x7E 首尾封装
- [x] 转义处理：0x7E → 0x7D 0x02，0x7D → 0x7D 0x01
- [x] 校验码：从消息头到消息体的异或值
- [x] 消息头属性字：bit15 加密、bit14 分包、bit13-10 保留、bit9-0 体长
- [x] 手机号 BCD 编码（6 字节）
- [x] 流水号范围 0-65535 循环
